# Thanish Thahir — portfolio

React 18 + Vite + Framer Motion. All copy and project data live in `src/content.js`.

```
npm install
npm run dev        # local dev
npm run build      # static site → dist/ (deploy to Vercel, Netlify, Firebase Hosting…)
```

- Design work images load from your Framer CDN (framerusercontent.com). If one fails, a typographic plate shows instead.
- IoT media (screenshots, bench clips) live in `public/media/`.
- To set credit on team builds, edit `credit` / `context` in `src/content.js`.
- Accent colour is `--accent` in `src/styles.css` (#0600FF, after Studio 0600FF).
